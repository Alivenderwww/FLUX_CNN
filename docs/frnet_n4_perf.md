## 外部存储占用

外部存储（4 个 NUMA mem，每 mem 16 MB）放两类数据：中间特征图 + 指令描述符。

**总占用**

| 类别 | 单 mem | 4 mem 合计 |
|---|---|---|
| 中间特征图（层间 OFM，int8） | 48 KB（并发峰值） | **192 KB** |
| 指令描述符（desc + SG cmd，32 B/条） | 48.3 KB | **193.2 KB** |
| **外部存储合计** | 96.3 KB | **385.2 KB** |

### 中间特征图（逐层）

DATA 区按生命周期分配：每层 OFM 被最后一个消费者读完后区域回收复用，故占用看**并发峰值**而非逐层求和。
`OFM/mem` = 该层 OFM 在单 mem 内字节数（W 切片时每 mem 只存自己 1/4 列段）；`DATA偏移` = DATA 区内 byte 偏移。

## 字段说明

列名沿用 CSV（机器生成），含义如下：

**通用后缀**
| 后缀 | 含义 |
|---|---|
| `_cyc` | 周期数（cycle，@100 MHz 每周期 10 ns） |
| `_pct` | 百分比 |
| `_fire` | 握手成功的拍数（RTL 中 `valid && ready` 那拍计数）。即"有效传输/触发发生"的次数 |
| `_beats` | AXI 突发传输的数据拍数，每拍 = 一个总线宽度 128 bit = 16 字节 |
| `_stall` | 上游有数据但下游没准备好接（`valid && !ready`，被反压）的拍数 |
| `_idle` | 下游准备好但上游没数据（`!valid && ready`，饿着）的拍数 |
| `_grant` | mm2s 仲裁器授予该 DMA 通道命令的次数 |

**Run**
| 列 | 含义 |
|---|---|
| `wall_cyc` | 墙钟（wall clock）总周期 = 端到端运行的总周期数 |
| `clk_mhz` | 时钟频率（MHz） |
| `fps` | 每秒帧数 = `clk_mhz × 1e6 / wall_cyc` |
| `total_mac_fire` | 全核全层 MAC 有效触发拍数总和 |
| `mac_pipe_pct` | MAC 流水线利用率 = `total_mac_fire / (cores × wall_cyc)` |

**Per-layer**
| 列 | 含义 |
|---|---|
| `pct_of_wall` | 该层周期占总墙钟周期的百分比 |
| `mac_pipe_pct` | 该层各核平均 MAC 流水线利用率 = `层fire / (cores × 层cyc)` |

**Per-core（IDMA SG 分发器周期分解）**
| 列 | 含义 |
|---|---|
| `idma/wdma/rdma/ocmd_grant` | 仲裁器授予 输入/权重/残差(bias)/输出 DMA 通道的次数 |
| `fetch_cyc` | 取 descriptor 的周期 |
| `ringwait_cyc` | 等 IFB ring 腾出空位（背压）的周期 |
| `issue_cyc` | 发 DMA 命令的周期 |
| `data_cyc` | 数据搬运的周期 |
| `done_cyc` | 收尾完成的周期 |

**Per-DDR**
| 列 | 含义 |
|---|---|
| `busy_cyc` / `busy_pct` | 该 DDR bank 忙的周期数 / 占总墙钟的百分比 |
| `aw_fire` / `ar_fire` | 写/读**地址**通道握手次数 = 发起的写/读突发事务数 |
| `w_beats` / `r_beats` | 写/读**数据**通道拍数（×16 = 字节数） |

**Per-layer-per-core**
| 列 | 含义 |
|---|---|
| `fire` | 该核该层 MAC 有效触发拍数 |
| `util_pct` | 该核该层 MAC 利用率 = `fire / cyc` |
| `act_stall` / `act_idle` | 激活输入侧（line_buffer→MAC）被反压 / 饿着 的拍数 |
| `wgt_stall` / `wgt_idle` | 权重输入侧（wgt_buffer→MAC）反压 / 饿着 的拍数 |
| `psum_stall` / `psum_idle` | 部分和（psum）侧反压 / 饿着 的拍数 |
| `acc_idle` | 累加器空闲拍数 |

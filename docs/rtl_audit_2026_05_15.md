## 已 revert (4 项假 fix / cancel pair)

1. **f4b0b59 S_FLUSH 100 拍**: 错 hypothesis ("axi_dm flush 慢"), 实测 H>32 mismatch 不变。浪费 100 拍/layer。
2. **3cccb6a hw_files OFB +1 slack**: 错 hypothesis (整图 fit chicken-egg), 实测加完仍 stuck。改 toolchain user-side。
3. **6490d27 ODMA 跳 S_STS**: 错 hypothesis ("axi_dm sts 偶丢"), 引入 secondary bug (r_yout_base 不推进)。
4. **f947cc9 r_yout_base S_STS→S_TX tlast**: 修 6490d27 引入的 secondary bug。同时 revert 等价 baseline。

## 仍待 audit (本次不动, 风险/影响范围大)

1. **6490d27 mm2s_arb 半 single-outstanding gate** (`data_empty_w`): 基线是全 multi-outstanding。3df4403 加严格 single-outstanding 是"axi_smc/noc multi-out 错位"假设。6490d27 改回半。**完全 revert 到 baseline 可能让 sim 加速,但要验证 board axi_dm 多 outstanding 是否安全**。
2. **6490d27 idma_sg r_done 不依 sts**: 改 r_done condition from `cmd_fires_total == sts_collected` to `cmd_idx >= cmd_count`。**逻辑上不严谨 (sts 收齐前就 done)**, 但 sim PASS 说明功能无影响。
3. **fbddd03 axi_m_mux 1-hot → generate-for**: Vivado 综合 workaround (LUT3 trim 失败)。逻辑等价,保留无害。
4. **e87ec55 / 0603352 / 5e074c0 multicore_top_vd100*.sv**: 废弃 axi_noc 工程文件,RTL/Versal/ 下还有 3 个文件不被 vd100_minimal 使用。**可删** (但 destruction 留下次手动)。
5. **04a6b16 mac_pe FLUX_MAC_BYPASS**: ifdef 包围,默认关。无影响,但可考虑彻底删除(若 board minimal 不再需要)。

## sim 验证

- **当前 RTL (4 项 revert 后)**: ResNet11 N=3 = **221250 cycles**, 11 layer bit-exact PASS。
- **revert 前 (含 f4b0b59 + 3cccb6a + 6490d27 ODMA + f947cc9)**: 221149 cycles。
- 差 +101 cycle (0.045% noise),sim IDEAL_SMC sts 几乎 0-latency。
- **功能正确性无影响**,perf 噪声级。

# Figure 2.1 Seven-level loop nest of 2-D convolution

## 在论文中的角色
- 首次引入：§2.2 卷积神经网络基础（段 "标准二维卷积可以用 7 层循环嵌套表达..." 末尾 [依赖: Fig.2.1]）
- 论证作用：用直观的循环嵌套结构 + 数据维度可视化，建立后续硬件循环嵌套（§4.2.7）与编译器循环展开（§4.3）的引用基线。让读者一眼看出 Cout / H_out / W_out 是输出空间维，Cin / Ky / Kx 是累加维，并理解为什么"循环展开顺序决定数据复用粒度"。

## 图类型
组合图：左侧为 7 层循环伪代码块，右侧为输入 / 权重 / 输出三张张量的轴示意图，中间用箭头连接每个循环变量与对应张量轴。

## 设计要素

### 必含元素
- **左侧（伪代码块）**：以等宽字体写出 7 层循环嵌套，外到内依次为 `for n in N → for co in Cout → for h_out in H_out → for w_out in W_out → for ci in Cin → for ky in Ky → for kx in Kx`，最内层写 `y[n,co,h_out,w_out] += x[n,ci,h_out·S+ky-P,w_out·S+kx-P] · W[co,ci,ky,kx]`；最后一行 `y[n,co,h_out,w_out] += bias[co]`（在循环外）。
- **右侧（张量轴示意）**：三个立方体——
  - 输入 X：四维（N,Cin,H,W），用蓝色立方体；H/W 维标注 stride 与 pad 影响（虚线扩展边界表示 pad）。
  - 权重 W：四维（Cout,Cin,Ky,Kx），用绿色立方体。
  - 输出 Y：四维（N,Cout,H_out,W_out），用橙色立方体。
- **中间连线**：从每条循环行的循环变量画带箭头连线，连到右侧张量对应轴；累加维（Cin/Ky/Kx）画到 X 与 W 上，输出空间维（Cout/H_out/W_out）画到 Y 上。

### 标注要求
- 标注外层 4 维（N/Cout/H_out/W_out）为"输出空间维"，内层 3 维（Cin/Ky/Kx）为"累加维"
- 在伪代码下方加一句斜体说明："外层维 → 输出像素索引；内层维 → 单像素累加贡献，共 Cin·Ky·Kx 次乘加"
- 张量立方体下方标轴名（例：N / Cin / H / W），不写具体数字

### 视觉层次
- 主角：7 层循环伪代码（占图面 60% 宽度）
- 配角：三张张量立方体（占图面 40% 宽度）
- 背景：连线为浅灰，避免干扰主体

## ASCII 示意稿

```
┌──────────────────────────────────────────────┐         ┌─────────────┐
│  for n  in 0..N-1:           // 输出空间维   │ ──ci─→  │   X         │
│   for co in 0..Cout-1:                       │ ──ky─→  │  (N,Cin,    │
│    for h_out in 0..H_out-1:                  │ ──kx─→  │   H,W)      │
│     for w_out in 0..W_out-1:                 │         └─────────────┘
│      // ↓ 累加维                             │
│      for ci in 0..Cin-1:                     │ ──co─→  ┌─────────────┐
│       for ky in 0..Ky-1:                     │ ──ci─→  │   W         │
│        for kx in 0..Kx-1:                    │ ──ky─→  │  (Cout,Cin, │
│         y[n,co,h_out,w_out] +=               │ ──kx─→  │   Ky,Kx)    │
│           x[n,ci,                            │         └─────────────┘
│             h_out·S + ky - P,                │
│             w_out·S + kx - P]                │ ──n──→  ┌─────────────┐
│         · W[co,ci,ky,kx]                     │ ──co─→  │   Y         │
│      y[n,co,h_out,w_out] += bias[co]         │ ─h_out→ │  (N,Cout,   │
│                                              │ ─w_out→ │   H_out,    │
│                                              │         │   W_out)    │
│  // 外层维 → 输出像素索引                    │         └─────────────┘
│  // 内层维 → 单像素累加 Cin·Ky·Kx 次         │
└──────────────────────────────────────────────┘
```

## 在论文中的角色
- 首次引入：§2.4 段 "行缓存（line buffer）是 streaming CNN 加速器的标志性数据通路..." [依赖: Fig.2.4]
- 论证作用：教科书型 line buffer + ring buffer 概念图（**通用概念**），后续 §4.2 的具体行级 ring（图 4.2）在此基础上做差异化。本图重在让不熟悉 streaming CNN 加速器的读者理解 "Ky 行驻留 + 滑窗滑过" 这一基础结构。

## 图类型
组合图：左侧为输入特征图（H×W 网格 + Ky×Kx 滑窗），右侧为环形 ring 结构（Ky 槽位 + 读写指针）。

## 设计要素

### 必含元素
- **左侧（输入特征图与滑窗）**：
  - 一张 H×W 网格图，画 Ky=3 行、W=10 列示意（H 与 W 不一定按比例）
  - Ky × Kx 滑窗（如 3×3）用红色框，沿 W 方向标向右滑动的箭头
  - 行编号 row 0 / row 1 / row 2 / ... / row H-1（左侧标注）
- **右侧（ring buffer 结构）**：
  - 圆环或竖直排列的 Ky 个 SRAM 槽位（slot 0 / slot 1 / slot 2）
  - 写指针 wp（绿色三角，指向"下一行将写入哪个 slot"），读指针 rp（蓝色三角，指向"滑窗当前从哪 Ky 个 slot 读"）
  - 标注："当滑窗到达行末时，最早一行被新进入的下一行覆写"——画 wp 顺时针前进的小箭头
- **中间连线**：滑窗的 Ky 行 → ring 的 Ky 个 slot，建立"滑窗读 = ring 读" 的对应

### 标注要求
- 图下方加一句："片上 ring 容量 = Ky × W_IN，与 H 解耦"——这是为后续 §4.2.2 row-credit ring 与"BRAM 占用与 H 解耦"建立铺垫
- 滑窗位置标注 "kx 沿 W 滑动，每滑一格 mac_array 完成一次 Cin × Ky × Kx 卷积"
- ring 的 Ky 槽位用不同浅色填充，便于区分

### 视觉层次
- 主角：左侧 H×W 网格 + 滑窗
- 配角：右侧 ring 结构
- 背景：连线、wp / rp 指针

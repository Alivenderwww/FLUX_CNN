# 图 3.2 多核拓扑与地址映射
# Figure 3.2 Multi-core topology and address mapping

## 在论文中的角色
- 首次引入：§3.3 段 "在单核基础上，多核拓扑通过 multicore_top 封装 N=2/4 核形态..." [依赖: Fig.3.2]
- 论证作用：展示 N=4 多核拓扑（顶层 multicore_top 封装 + axi_2to3/4to5 fanout + axi_lite_1to4 fanout）+ DDR 与各核 IFB 地址段划分。后续 §4.5 的 W 切片几何（图 4.10）与跨核直送（图 4.11）在该拓扑上展开。

## 图类型
拓扑图 + 地址段表：上半为 N=4 多核拓扑（4 个 core 实例 + fanout 组件 + 单 AXI 主口对外），下半为 DDR 64-bit 地址空间分段表。

## 设计要素

### 必含元素
- **上半（拓扑）**：
  - 顶层框 `multicore_top` 包含 4 个 core 实例（core[0]/core[1]/core[2]/core[3]），每个 core 内部仍是图 3.1 的单核结构（用浅灰小框示意，不展开 5 模块）
  - 4 个 core 共享：`axi_lite_1to4`（AXI-Lite fanout，把单 AXI-Lite 从口分到 4 个 core 的 csr）+ `axi_4to5`（AXI4 主口聚合，把 4 核 AXI 主请求聚合到 1 个对外主口）
  - 顶层对外仍是单 AXI4 主口 + 单 AXI-Lite 从口
- **下半（地址映射表）**：

| 地址段 | 起始 | 结束 | 用途 |
|--------|------|------|------|
| DDR | 0x0000_0000 | 0x7FFF_FFFF | 共享 DDR：descriptor list / 权重 / 中间 FM |
| Core[0] IFB | 0x8000_0000 | 0x8FFF_FFFF | 第 0 核 IFB 区段（256 MB 地址，实际 IFB 容量 8192 word） |
| Core[1] IFB | 0x9000_0000 | 0x9FFF_FFFF | 第 1 核 IFB 区段 |
| Core[2] IFB | 0xA000_0000 | 0xAFFF_FFFF | 第 2 核 IFB 区段 |
| Core[3] IFB | 0xB000_0000 | 0xBFFF_FFFF | 第 3 核 IFB 区段 |

- 在拓扑图中每个 core 旁标注其 IFB 地址段（如 core[0] 旁写 "IFB @ 0x8000_0000"）
- 跨核 SRAM 直送（M2 push）的箭头：在 core[i] → core[(i+1)%4] IFB 之间画一条虚线箭头，标 "M2 push（图 4.11 详）"

### 标注要求
- 拓扑图右上角加注 "外部仍是 1 AXI4 + 1 AXI-Lite（与图 3.1 单核接口约定一致）"
- 4 核共享 axi_4to5 仲裁的位置标 "共享 DDR 通道，多核扩展瓶颈定位见 §5.6"
- 地址表脚注："统一规则：Core[i] IFB 起始 = 0x8000_0000 + i × 0x1000_0000，编译器与 host 共享同一地址映射，N=1/2/4 不变"

### 视觉层次
- 主角：4 个 core 实例（最大）
- 配角：fanout 组件 + 地址表
- 背景：跨核虚线箭头

# 图 4.3 16×16 OS + 列广播 MAC 阵列
# Figure 4.3 16×16 output-stationary MAC array with column-broadcast dataflow

## 在论文中的角色
- 首次引入：§4.2 段 "第三层骨架是 16×16 INT8 OS+列广播 MAC 阵列..." [依赖: Fig.4.3]
- 论证作用：可视化 16 行 × 16 列共 256 个 INT8 MAC 单元的 OS + 列广播数据流——激活沿 16 列广播给同列 16 个 PE，权重沿行广播给同行 16 个 PE，PE 间无数据移动。对应贡献 C1.1，是 §3.4.1 数据流选择论证的图示根据。

## 图类型
矩阵图：16×16 PE 网格 + 顶部权重输入条 + 左侧激活输入条 + 标注 PE 编号；底部画输出 PSUM 收尾。

## 设计要素

### 必含元素
- **16×16 PE 网格**：
  - 每个 PE 用小方块表示，标编号 PE(i,j) (i = 0..15 行, j = 0..15 列)
  - 每个 PE 内部画一个简化乘加单元：act × wgt → +PSUM
  - PE(i,j) 累加输出像素 (co=i, ?, ?, w_offset=j)（根据当前 cfg）
- **左侧激活输入条**：16 行 INT8 通道，每行标 cin_i (i=0..15)；标注 "act 沿列广播：每行 cin_i 同时广播到第 i 行 16 个 PE 同行"
- **顶部权重输入条**：16 列 INT8 权重，每列标 wgt_co_j (j=0..15)；标注 "wgt 沿行广播：每列 wgt_co_j 同时广播到第 j 列 16 个 PE 同列"
- **底部 PSUM 收尾**：16 列 32-bit PSUM 输出，标 "PSUM 32-bit → parf_accum"
- **关键说明**："PE 间无任何数据移动 — OS：每个 PE 内部 PSUM 寄存器累加自身像素的 Cin·Ky·Kx 次乘加"

### 标注要求
- 用三种颜色：激活蓝、权重绿、PSUM 橙
- 在阵列正中心加大字标 "16 × 16 = 256 INT8 MAC，OS + 列广播"
- 阵列下方加："Cin ≥ 16 且 Cout ≥ 16 时填满 256 MAC；Cin < 16 / Cout < 16 时部分行 / 列空转 → §4.3 编译器侧 Ky-fold / S2D 把 Cin < 16 折回满载"
- 用箭头明确广播方向：左侧 act 向右"水平广播"（不是流过，是同时到达每个 PE），顶部 wgt 向下"垂直广播"

### 视觉层次
- 主角：16×16 PE 网格
- 配角：左 / 顶部输入条
- 背景：底部输出 + 数据流方向箭头

# 中文本科毕业论文规范（共用 spec，所有 Writer 必读）

> 用户验收意见（2026-05-01）：当前 paper.md 是英文 IEEE 会议风格，但实际目标是**中国大学集成电路设计与集成系统专业本科毕业论文**。
> 本规范是后续所有 Writer 任务的共用参考。**任何 Writer 在写作前必须先读完这份 spec**。

---

## 1. 整体定位

- **学科**：集成电路设计与集成系统（理工科本科毕业论文）
- **语言**：**中文**（中文表达 + 中文思维，不是英文直译）
- **目的**：毕业设计说明书 + 毕业论文（兼具）。重点反映"运用所学的数学、自然科学、工程基础和专业知识解决复杂问题"
- **创新意识体现**：在设计环节中体现新思想、新观点、新规律、新研究方法、新结果

## 2. 文档结构（强制）

按顺序：

1. **封面 / Frontmatter**（标题 / 作者 / 单位 / 指导老师 / 日期等占位 [TBD]）
2. **摘要**（中文）：500 字以内，含目的、方法、结果、结论；**不允许出现插图**，可有重要表格；单页限制
3. **关键词**（中文）：3-5 个，"关键词："引导不可省略；尽量用《汉语主题词表》规范词
4. **Abstract**（英文）：内容与中文摘要对应；第三人称；最好现在时态
5. **Key words**（英文）：与中文关键词一致；**与 Abstract 正文之间空一行**
6. **引言 / 文献综述**（**单独成章，~8000 字**）：说明论文主题与选题范围、对相关文献的评述、本论文要解决的问题；**禁止与摘要内容雷同**；如实引用前人结果，明确写出同行已有成果
7. **正文章节**（多章）：本研究内容总体方案 / 硬件软件设计 / 实验装置测试 / 数据结果分析 / 理论分析 / 创新与改进与实际应用
8. **总结**（独立章）
9. **参考文献**（按引用顺序编号，规范格式见 §6）
10. （可选）致谢 / 附录

## 3. 摘要 / Abstract 具体要求

### 中文摘要
- 篇幅：≤500 字（**严格上限**）
- 内容：目的 / 方法 / 结果 / 结论
- 单位：国际标准计量单位制
- 数字：除特别情况外一律阿拉伯数字
- 不允许插图，重要表格可入

### 关键词
- 数量：3-5 个
- 引导词："关键词：" 不可省略
- 选词：《汉语主题词表》规范词为佳
- 与英文 Key words 一致

### 英文 Abstract
- 内容对应中文摘要
- 第三人称
- 最好现在时态

### Key words
- 与中文关键词一致
- 与 Abstract 正文之间空一行

## 4. 引言 / 文献综述（~8000 字）

- 说明论文主题与选题范围
- 对相关文献的评述（包括 FLUX_CNN 相关 prior art 全部覆盖：Eyeriss / TPU / NVDLA / Gemmini / MAERI / Eyeriss-v2 / Tangram / fpgaConvNet / Snowflake / Aydonat / Caffeine / Alwani Fused-layer / Kang AoCStream / Liu Full-Stack / Direct Convolution / Winograd / im2col / etc.）
- 说明本论文要解决的问题
- 与历史回顾、前人工作文献评论、理论分析相结合
- **如实引用前人结果**——明确写出同行相近的和已取得的成果，避免抄袭之嫌
- **禁止与摘要内容雷同**

## 5. 正文要求

正文（含引言或文献综述部分）应包括：

1. **本研究内容的总体方案设计与选择论证**
2. **硬件与软件的设计计算，实验装置与测试方法**
3. **试验方案设计的可行性、有效性、技术经济分析**：试验数据结果的处理与分析论证；理论计算结果的分析与展望
4. **本研究内容的理论分析**：全面、客观地阐述；着重指出创新、改进与实际应用；引用他人成果时单独书写并注明出处，不与本人理论分析混淆；引用其它领域理论时说明该理论出处与可行性

风格要求：
- 论点正确，推理严谨，数据可靠，文字精练，条理分明
- 文字图表规范、清晰、整齐
- 语句通顺，达到"正确、准确、明确"
- 计算单位用国务院《统一公制计量单位中文名称方案》规定名称
- 各类单位、符号全文统一
- 引用前人材料必须引证原著文字

## 6. 参考文献规范（**关键**）

### 正文中引用格式
- 用方括号 + 阿拉伯数字按顺序，**右上角标**形式标注在引用处
- 例：FLUX_CNN 借鉴 Eyeriss 的行固定数据流<sup>[5]</sup>

### 参考文献条目格式

按引用顺序编码。作者姓前名后（外文作者名缩写）。作者间用","。**作者少于 3 人全部写出，3 人以上只列前 3 人后加"等"或"et al"**。

按文献类型不同使用不同格式：

**①专著**：
```
[序号] 作者. 专著名[文献类型标志]. 出版地: 出版者, 出版年.
```

**②期刊析出文献**（**注意区分卷和期号**）：
```
[序号] 作者. 题名[文献类型标志]. 刊名. 出版年, 卷号(期号): 起止页.
```

**③会议论文**：
```
[序号] 作者. 篇名[文献类型标志]. 会议名, 会址, 开会年: 起止页.
```

**④文集析出文献**：
```

```

**⑤学位论文**：

**⑥专利文献**：

## 7. 规范表达

### 名词术语
- 全国自然科学名词审定委员会审定的自然科学名词术语优先
- 工程技术名词术语按相关标准
- 公认共知的名词术语
- 自拟名词术语，第一次出现时加注说明
- 同一概念全文术语一致
- 外国人名可使用原文，不必译出
- 机关 / 团体 / 学校 / 研究机构 / 企业第一次出现时写全称

### 数字
- 符合 GB/T 15835-1995《出版物上数字用法的规定》
- 一般用阿拉伯数字（年代、世纪、月日、分数、百分数、计量值）
- 概数 / 古汉语习惯 / 法律条目用汉字数字（"几十年"、"数百"、"五四运动"）

### 外文字母（**核心规则**）
**严格控制外文字母 / 单词使用**——可在草稿大量用英文，但**最终稿需保证绝大部分非专业术语英文转中文**，并保持中文词含义一致。
严格区分文种、大小写、正斜体、黑白体、上下标。

#### 斜体
表示量的符号：
- 变量符号 / 变动附标 / 函数：*x*, *y*, *f*(*x*)
- 字母表示的数 / 点 / 线 / 面 / 体 / 图形：*A*, *B*
- 特征数符号：*Re*（雷诺数）/ *Fo*（傅里叶数）/ *Al*（阿尔芬数）
- 在特定场合视为常数的参数
- 矢量、矩阵：**斜体黑体**

#### 正体
表示名称及代号：
- 已知函数：sin, exp, ln, cos
- 数学常数（其值不变）：e=2.7182818..., π
- 算子（已定义的）
- 法定计量单位 / 词头 / 量纲符号：m, kg, MHz, μs
- 数学符号
- 化学元素符号：H, O, Si
- 机具 / 仪器 / 设备 / 产品的型号、代号、材料牌号：XC7K325T, ResNet-18
- 硬度符号
- 不表示量的外文缩写字：CPU, FPGA, SRAM, DSP, MAC, PE, AXI, DMA
- 表示序号的拉丁字母：a), b), c)
- 量符号中区别其它量的下角标（具有特定含义的非量符号）

### 中英文混排（**md 格式特别注意**）
**markdown 与 word 规范不一致**——本论文要求：

> **英文（或数字）与中文之间无空格**

正确：`Key words与摘要正文之间空一行` / `XC7K325T-2上跑回归测试`
错误：`Key words 与摘要正文之间空一行` / `XC7K325T-2 上跑回归测试`

**唯一例外**：英文短语内部空格（如 `Key words` 内）保留；连续英文 / 数字算法块（公式 / 代码）保留原空格。

## 11. 中文工科本科论文范文学到的具体规则

> 本节是 2026-05-06 用户提供的优秀硕士毕业论文范文（`paper/参考/参考范文.md`）阅读后总结的具体规则与反例对照。**本节是所有"格式规范化"任务的核心参考**。

### 11.1 文档结构（强制）

```
标题（中英双语，并列在 # 后）
中文摘要 + 关键词
ABSTRACT（英文）+ Key Words
主要符号表 ← 必须有，独立成节
1 绪论                                  ← 一级标题用阿拉伯数字，无"第 N 章"前缀
  1.1 研究背景与意义
  1.2 国内外相关研究现状（含 1.2.1 / 1.2.2 子节）
  1.3 研究目标与研究内容（含 1.3.1 / 1.3.2 / 主要贡献）
  1.4 论文组织结构
2 [理论基础章]                          ← 应有独立的理论基础章
3 [设计章]
4 [核心实现章]                          ← 通常最长最详
5 [验证章]                              ← 含功能/板级/性能/对比子节
6 结论与展望
  6.1 结论
  6.2 创新点
  6.3 展望
参考文献                                ← 独立无章号，GB/T 7714 格式
（致谢 / 附录 可选）
```

### 11.2 章节编号规则（核心）

| 项 | 规则 | ✅ 正例 | ❌ 反例 |
|---|---|---|---|
| 一级标题 | 阿拉伯数字，无"第 N 章"前缀 | `## 1 绪论` / `## 6 结论与展望` | `## 第一章 绪论` / `## 第六章 总结` |
| 二级标题 | 阿拉伯数字两级 | `### 1.1 研究背景与意义` | `### 一、研究背景` / `### 1.1. 研究背景` |
| 三级标题 | 阿拉伯数字三级 | `#### 1.2.1 脉冲神经网络` | `#### (1) 脉冲神经网络` |
| 章末小结 | 用 `### N.M 本章小结` 而不是单独开节 | `### 2.4 本章小结` | `## 2.4 本章小结` / `# 本章小结` |
| 结论章拆分 | 强制拆 3 节 | `### 6.1 结论` `### 6.2 创新点` `### 6.3 展望` | 单一一节合在一起 |

### 11.3 中英文混排（最高频违规点）

| 项 | 规则 | ✅ 正例 | ❌ 反例 |
|---|---|---|---|
| 中文与英文/数字之间 | **无空格** | `XC7K325T-2上跑22个case` | `XC7K325T-2 上跑 22 个 case` |
| 连续英数块内部 | **保留**原有空格 | `Xilinx AXI DataMover IP` / `100 MHz` / `593K cycles` | `XilinxAXIDataMoverIP` |
| 中文与中文标点 | **无空格**（标点本身已含间距） | `首先，引入...` | `首先 ， 引入...` |
| 英文与英文标点 | 标点后 1 空格 | `Vivado, ModelSim, PyTorch` | `Vivado,ModelSim,PyTorch` |
| 数字与单位 | **保留**单空格（属"连续英数块"） | `100 MHz` / `1.9 W` / `48.08 GOPS` | `100MHz` / `1.9W`（视为不规范，但范文偶有连写） |
| 数字与百分号 | **无空格** | `86.6%` / `12.5%` | `86.6 %` |

### 11.4 外文字母正斜体（中文工科论文核心）

| 类别 | 字体 | 例子 |
|---|---|---|
| 缩写（不表示量） | **正体** | FPGA / PE / MAC / CNN / INT8 / DSP / BRAM / LUT / AXI / DMA / SRAM / DDR / SDP / RTL / IP / KB / MB / MHz / GOPS / FPS / RMSE |
| 单位 | **正体** | m / kg / MHz / GOPS / μs / ms / KB / MB / W |
| 已定义函数 | **正体** | sin / exp / ln / cos / max / min |
| 数学常数 | **正体** | e / π |
| 化学元素 | **正体** | H / O / Si |
| 器件型号 / 材料牌号 | **正体** | XC7K325T-2 / Kintex-7 / ResNet-18 / Zynq XC7Z100 |
| 表序号字母 | **正体** | a) / b) / c) |
| **变量符号 / 函数自变量** | **斜体** | *x* / *y* / *V*(*t*) / *f*(*x*) |
| **代表点/线/面/图形** | **斜体** | *A* / *B* / *P*₁ |
| **特征数符号** | **斜体** | *Re*（雷诺数） / *Fo*（傅里叶数） |
| **特定场合视为常数的参数** | **斜体** | *T*（时间步长，作为参数） / *N*（核数） |
| **矢量/矩阵** | **斜体黑体** | **A** / **B** / **W** |

**实操要点**：markdown 中斜体用 `*x*`（单星）。**禁止**用 `*FPGA*`（缩写不应斜体）或 `_x_`（下划线斜体在某些渲染器有问题）。

### 11.5 段落写作的高频模式（从范文学到的句式模板）

#### A. "如图 X.Y 所示"引导句（**最高频**）

范文几乎每个图引用都用此句式：

✅ **正例**：
> 如图 4.5 所示，输入特征图首先进行数据准备，随后采用本文提出的基于输入与坐标编码的存储方式进行特征图编码。
> 如图 2.3 所示为脉冲神经网络逐步传播计算图。
> 如表 5.1 所示为加速器效率比较。

❌ **反例**（我们 paper-zh.md 当前写法）：
> 见 Tab.5。
> Fig.1 展示了顶层框图。
> 表 5-5 把 86.6% 与 97% 并排列出。

**修正模板**：所有"`见图 X` / `Fig.X 展示` / `表 X.Y 列出`" → 改为 "`如图 X.Y 所示，`" 或 "`如图 X.Y 所示为...`"

#### B. "针对 XXX 问题，本论文提出 YYY"（贡献引出）

✅ **正例**：
> 针对当前脉冲神经网络卷积计算存在的存储空间和计算资源的瓶颈问题，提出了一种基于输入和坐标编码的特征图编码方法...

❌ **反例**：
> Our key contribution is...
> 我们贡献了...

#### C. 引用前人工作（**严格句式**）

✅ **正例**（范文用法）：
> Chen G 等<sup>[6]</sup>**在 2023 年发表的研究论文中**提出了两种能耗计算公式...
> Liu Y J 等<sup>[25]</sup>**在 2022 年的论文**提出了一种基于 FPGA 的通用神经形态硬件加速平台...

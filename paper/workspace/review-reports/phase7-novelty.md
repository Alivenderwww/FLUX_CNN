# 新颖性评审报告 Phase 7（v3）

## 第二次评审

### 判定：PASS

立项摘要（≤3 句）：
- 本工作定位为面向端侧流式计算场景的 INT8 卷积加速器 FLUX_CNN，最终目标载体为 ASIC，FPGA（XC7K325T）仅作功能与综合可行性验证；§1.1 第 3 段、§5.4.2 与 §5.4.3 均明确"FPGA 是验证平台、ASIC 是最终目标"。
- 与 Eyeriss / NVDLA / VTA / Gemmini 等参考工作的差异核心在于：单核侧"配置寄存器 + 6 层嵌套自循环 FSM"消除运行时取指/译码、保留宏观 Task Descriptor 接口承担多核多层调度（§1.3 第一条 / §3.4 / §6.2 创新点 1）；编译器侧 Ky 折叠 + 空间到深度（S2D）两项 PE 利用率优化在硬件不变前提下提升小 Cin / 大 stride 层的 PE 利用率（§4.8 / §4.9 / §6.2 创新点 3）；多核 W 切片配合跨核 SRAM 直送 push 避免 OFM 经 DDR 中转（§4.11 / §6.2 创新点 4）。
- 主要风险点（仍可接受）：表 5.6 中多数对照行的实测峰值算力 / 功耗 / 能效仍为 [CHECK]，但 §5.6 行文中已明确说明本工作"峰值算力处于端侧加速器中下区间"且"FPGA Fmax 与 DSP 推断率为后续优化方向"，未对未填的对照单元做强声明，定位姿态保守，可在数据补齐后进一步收敛。

### 假想审稿人模式自查

- **Reviewer A（系统派）**："分层调度架构 + 6 层嵌套 FSM" 是否够新？答：与 NVDLA 的"多模块独立 FSM" 与 VTA 的"完整 VLIW 张量指令" 已在 §1.2.2 显式区分——前者无核外宏指令通路，后者保留完整取指译码。本工作的差异化（"启动后 4 寄存器 + DFE 描述符流自动驱动一层 50+ 个 cfg 写"）在 §3.4 / §4.7 给出具体接口形态，可经受系统派审稿。
- **Reviewer B（算法派）**：Ky 折叠 / S2D 是否新？答：Ky 折叠是面向小 Cin 卷积层的 cin 维填充技术，与 SCNN 的稀疏跳零、Eyeriss v2 的灵活 mesh 切换路径不同——后两者依赖剪枝/稀疏数据特性，本工作不依赖。S2D 与 ShuffleNet 等算法层 space-to-depth 不同——这里是编译器侧的纯硬件视角等价变换，对模型权重无侵入。§4.8 / §4.9 数学推导自洽。
- **Reviewer C（应用派）**：能效数据完整吗？答：§5.4.3 表 5.3 与 §5.6 表 5.6 的功耗 / 能效格仍为 [CHECK]，但 §5.6 行文与 §6.3 展望均诚实说明"基于 Vivado Power Estimator 的分析尚未与板级实测对齐 ... 后续需要在目标 FPGA 板卡上完成片外 DDR、AXI 互连与 SDP 量化链的实测功耗分解"，未做不实声明，应用派审稿可接受"FPGA 验证 + ASIC 后续"的定位。

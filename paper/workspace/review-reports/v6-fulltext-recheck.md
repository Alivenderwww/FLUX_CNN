#### 唯一违规：L510

```
本节据此结构性特征给出一种把单核mac_array中相邻两列的INT8乘法器合并映射到一个DSP48E1块上的实现方案，
使整个16×16阵列的256个乘法器从查找表实现迁移至DSP块实现。
```

**问题**：在正文实现节（§4.12 不是"本章小结"也不是"结论章"）使用「**本节...给出一种...方案**」，正中 spec §11.12B 表"自我标注"反例（"本节给出..."）。

**修复建议**（直接删除元话语，改为陈述方案本身）：

```
据此结构性特征，可把单核mac_array中相邻两列的INT8乘法器合并映射到一个DSP48E1块上，
使整个16×16阵列的256个乘法器从查找表实现迁移至DSP块实现。
```

或：

```
利用这一结构性特征，可在DSP48E1块上将相邻两列的INT8乘法器合并实现，
使整个16×16阵列的256个乘法器从查找表实现迁移至DSP块实现。
```

> 注：v6 形式化是机械删空行 + LaTeX 包裹，未必引入了这一违规——L510 可能在 v5 已存在。但本任务要求是"复审形式化是否引入新违规"+ 全文合规独立复核，因此仍计为 FAIL，需在封版前一并修复。

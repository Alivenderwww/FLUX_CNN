# v6.1 LaTeX 公式边界修复摘要

范围：paper.md §4.8（行 455）至文末（行 ~924）。§4.7 及之前不动。

## 任务

修复 v6 转换后残留的"数学公式分裂"问题：比较运算符 / 等号 / 数学常量被排除在 `$...$` 外的情况。

## 修改条目数

| 模式 | 描述 | 行级出现处数 | 实际编辑行数 |
|---|---|---|---|
| 模式 1 | `$X$<Y` / `$X$=Y` / `$X$≥Y` 等比较或赋值在公式外 | ~70 | 9 |
| 模式 2 | `X<$Y$` 比较运算符在公式前 | 0 | 0 |
| 模式 3 | `$X$$\geq$Y` / `$X$×$Y$` 紧邻数学块 | ~6 | 包含在模式 1 行内 |
| 模式 4 | v6 残留 `*X*` 伪斜体 / `"中文` 引号（§4.8+） | 0 | 0 |

## 典型修改示例

**示例 1**（行 457，§4.8 开篇）：

修改前：
```
针对$C_{\mathrm{in}}$<NUM_PE=16的卷积层（如ResNet早期层$C_{\mathrm{in}}$=3、MobileNet深度卷积$C_{\mathrm{in}}$=1），MAC阵列模块在Cin维存在严重列空转，理论PE利用率仅$C_{\mathrm{in}}$/16。
```

修改后：
```
针对 $C_{\mathrm{in}} < \mathrm{NUM\_PE} = 16$ 的卷积层（如ResNet早期层 $C_{\mathrm{in}} = 3$、MobileNet深度卷积 $C_{\mathrm{in}} = 1$），MAC阵列模块在Cin维存在严重列空转，理论PE利用率仅 $C_{\mathrm{in}} / 16$。
```

```

修改后：
```
$C_{\mathrm{in}} < 16$ 区间... $C_{\mathrm{in}} \geq 32$ 时走通道切片

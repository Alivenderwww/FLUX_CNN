## 处理规则

| 场景 | 操作 |
|---|---|
| 中文+空格+英文字母 | 删空格 |
| 英文字母+空格+中文 | 删空格 |
| 中文+空格+数字 | 删空格 |
| 数字+空格+中文 | 删空格 |
| LaTeX 公式`$...$`+空格+中文 | 删空格 |
| 中文+空格+LaTeX 公式`$...$` | 删空格 |
| 数字+空格+`%` | 删空格 |
| 数字+空格+单位（MHz/W/GMAC/fps/word/字/层/路/核/块/个/次 等） | **保留**单空格 |
| 引导句"如表 X.Y 所示"/"如图 X.Y 所示"/"如公式 (X) 所示" | **保留**空格 |
| 表格 `|` 分隔符周围 | **保留**空格 |
| HTML 注释 `<!-- ... -->` 内 | **不改** |
| 行内代码 `` `xxx` `` 内 | **不改** |
| 章节标题 `### N.M ...` | **不改** |
| LaTeX 公式 `$...$` 内部空格 | **不改** |
| 数字+空格+nm（工艺节点）/MHz/GHz/GOPS/TOPS | **保留**（视为连续英数块） |

## 处理方式

逐行 Edit（不批量 replace_all，避免误改单位、数字+×倍率符等），按：
1. 中→英方向（`中文 字母` → `中文字母`）
2. 英→中方向（`字母 中文` → `字母中文`）
3. 数→中方向（`数字 中文` → `数字中文`）
4. 中→数方向（`中文 数字` → `中文数字`）
5. 公式→中方向（`$...$ 中文` → `$...$中文`）
6. 中→公式方向（`中文 $...$` → `中文$...$`）
7. 数字+%（`数字 %` → `数字%`）

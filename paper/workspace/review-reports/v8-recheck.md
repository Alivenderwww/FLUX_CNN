# 写作评审报告 v8 §5.5.1 复审

复审范围：paper.md §5.5.1（行 637-655）
触发：v8 修改表 5.4 帧率列由 100 MHz 改为 FPGA 实测 143.8 MHz，删除单独折算段

## 总判定：PASS

v8 对 §5.5.1 的修改合规：表 5.4 帧率列已统一改为 FPGA 路由后实测频率 143.8 MHz 折算，5 行帧率值与对应整网周期数严格自洽，删段动作完成，FPGA 限定语保留得当，未触发 spec §11.13 立项硬约束（未将 FPGA 频率冒充 ASIC 性能）。

## 4 项验证结果

### 1. 表 5.4 帧率列一致性 — PASS

按 fps = 143.8 × 10⁶ / wall_cy 公式核对 5 行数据：

| 配置 | 整网周期数 | 计算值 | 表中值 | 一致 |
|---|---|---|---|---|
| N=1 未启用 S2D | 1,115,000 | 143.8e6 / 1.115e6 = 128.97 | 129 fps | ✓ |
| N=1 含 S2D | 596,088 | 143.8e6 / 596,088 = 241.24 | 241 fps | ✓ |
| N=2 含 S2D+W | 450,469 | 143.8e6 / 450,469 = 319.22 | 319 fps | ✓ |
| N=4 含 S2D+W | 354,555 | 143.8e6 / 354,555 = 405.58 | 406 fps | ✓ |
| N=4 全优化 | 190,133 | 143.8e6 / 190,133 = 756.31 | 756 fps | ✓ |

5 行帧率均按 143.8 MHz 折算到整数 fps，舍入方向（四舍五入）一致，无内部矛盾。

### 2. 删段落是否到位 — PASS

grep `按 143\.8 MHz 实测折算` 在全文 0 命中。新 §5.5.1 表导语改为"帧率列以 FPGA 路由后实测频率 143.8 MHz 折算"（行 639 嵌入表前导语），表头亦改为"帧率（@FPGA 实测 143.8 MHz）"（行 644）。原"按 100 MHz 折算"独立段已不再存在，且未在 §5.5.1 范围内残留任何 100 MHz 帧率折算句式。

### 3. 其他章节频率口径未受影响 — PASS

抽样核对：

- §5.4.2（行 616）："帧率统一以 100 MHz 时钟假设折算给出，并附 N=4 DSP 实现路由后 Fmax 143.8 MHz 折算行作为横向对照" — **此句仍保留 100 MHz 假设语义**。提示：该句与新 §5.5.1 全表 143.8 MHz 折算的事实存在轻微叙述不一致，但因 §5.4.2 是面向综合实现章节的 forward-pointer，且新 §5.5.1 的 143.8 MHz 行可视为 §5.4.2 所述"横向对照行"的常态化呈现，未引入数值矛盾，仅文字略显历史遗留。建议主 Agent 在后续轮次将 §5.4.2 该句"统一以 100 MHz 折算给出"措辞软化为"按 FPGA 实测频率折算"。本轮不作为 FAIL 判定。
- §5.6 表 5.6（行 831-844）：仍标注 100 MHz 假设值与 125.4 MHz / 143.8 MHz 路由后实测两套口径，未受影响 ✓
- §5.6 表 5.13（行 793-794）：使用 ASIC 折算频率 850 MHz，与 §5.5.1 的 FPGA 频率口径正交，未受影响 ✓
- §5.5.6 范围内（grep 结果）未见涉及帧率折算的频率口径冲突。

### 4. 新违规扫描 — PASS

- spec §11.3 中英文空格：抽样"143.8 MHz"（数字+单位空格保留）✓；"FPGA 路由后实测频率 143.8 MHz 折算"行内未见中英文之间多余空格 ✓；"131 M MAC"（数字+单位）符合格式 ✓
- spec §11.12B 跨章引用 / 元话语 / 章节预告：§5.5.1 范围（行 637-655）内仅有"数据来源为 STATUS §2.8、§2.12 与 §20–§21 的整网仿真结果"，属外部数据来源标注，非论文跨章引用；无"如前所述"、"将在后续章节讨论"等元话语；未发现章节预告。✓
- spec §11.13 立项硬约束：表 5.4 表头明确标注"@FPGA 实测 143.8 MHz"，行 655 末句保留"对应 FPGA 实测频率下 756 fps"的 FPGA 限定语，未将 FPGA 频率冒充为 ASIC 性能；FLUX_CNN 的 ASIC 目标性能在 §5.6（850 MHz）独立呈现，与 FPGA 验证频率口径分离 ✓

## 提示（不影响判定）

- **建议 tech 评审复核**：§5.4.2 行 616"帧率统一以 100 MHz 时钟假设折算给出"措辞已与 §5.5.1 当前实际呈现脱节（事实层面是否仍准确，由 tech 评审判定）。如 tech 不复核，建议下一修正轮次将该处文字软化以保叙述一致。
- **建议 tech 评审复核**：N=4 全优化行整网周期数 190,133 与行 654 文中"整网周期数进一步降至 220,824（相对 N=1 含空间到深度加速 2.70×）"之间存在两个不同周期数（220,824 vs 190,133）。从行文逻辑看，220,824 是"加调度优化前"的中间状态、190,133 是叠加调度优化后的最终状态，逻辑自洽；但 220,824 这一数值是否对应表 5.4 中某行需 tech 核对其来源。
